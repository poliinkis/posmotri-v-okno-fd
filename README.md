«Посмотри в окно»

Интерактивное видео-приложение с поиском и подгрузкой карточек. Скрипты для работы приложения уже предоставлены обучающей платформой, задача проекта — стилизовать интерфейс и компоненты.

Технологии: HTML, CSS (Flexbox/ Grid), базовый JavaScript

Особенности проекта:

Pixel Perfect верстка по макету.
Кастомные формы и чекбоксы, стилизованные кнопки.
Поддержка состояний карточек: текущая, активная, при наведении, в фокусе.
Прелоадеры и обработка ошибок при загрузке данных.

Запуск: открыть index.html в браузере.
